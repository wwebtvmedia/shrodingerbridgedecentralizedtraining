HarnessDroid Agent Platform

An Android autonomous execution harness enabling local AI agents to discover, negotiate, and execute tools via the Model Context Protocol (MCP) over AIDL IPC, guarded by Human-in-the-Loop permission controls.

extension MCP over Android AIDL

HarnessDroid translates standard Model Context Protocol (MCP) JSON schemas into cross-process Android intents:

  • Dynamic Tool Discovery: Broadcasts com.ai.harnessdroid.ACTION_PROVIDE_TOOLS to identify all tool providers installed on device.
  • Schema Normalization: Parses JSON-RPC 2.0 tool definitions (`tools/list`, `tools/call`) into Android Parcelable bundles.
  • Loose Coupling: Tool providers run in separate sandboxed processes; a crash in a third-party tool does not crash the agent.
  • Zero Cloud Relays: Tool execution executes locally on device via native IPC.

verified_user Human-in-the-Loop (HITL) Firewall

Security and user safety are enforced at the OS level before executing tools:

// MCP Tool Execution Intent
Intent intent = new Intent("com.ai.harnessdroid.ACTION_PROVIDE_TOOLS");
intent.putExtra("method", "tools/call");
intent.putExtra("tool_name", "schrodinger_bridge_sample");
intent.putExtra("arguments", "{ \"steps\": 50, \"solver\": \"heun\" }");

// Guarded by HITL Risk Tier:
// Tier 1 (Safe): Read-only memory & sensors -> Auto-approve
// Tier 2 (Elevated): Network send & file write -> Notification
// Tier 3 (Critical): Model weight override -> Explicit Dialog

sync The Autonomous Agent Loop

  • 1. Goal Parsing: Converts user prompt into structured execution graph with dependencies.
  • 2. Tool Selection: Uses Tree4Five LLM to select tool name and format JSON arguments.
  • 3. Permission Gate: Checks user consent and safety bounds.
  • 4. IPC Execution: Dispatches call via AIDL, receives result Parcelable.
  • 5. Reflection: Analyzes observation against goal and iterates until completion.
