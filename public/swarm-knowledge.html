An open, mathematically grounded protocol specification for decentralized knowledge negotiation, multi-hop evidence synthesis, and cross-swarm artifact exchange with strict hallucination firewalls.

layers Node Classification Hierarchy

OSP v0.6 defines asymmetric node capabilities to support resource-constrained edge devices alongside server clusters:

Class Role Depth Bounds Generation Capability
N1 (Thin Origin) Querying & Local Validation D0 – D1 Zero (Validation only)
N2 (Full Responder) Synthesis & Local Inference D0 – D3 Local Small Models / On-device
N3 (Provider-Backed) Gateway / Deep Reasoning D0 – D5 External Provider / Large GGUF

Nodes dynamically advertise their tier in handshake headers and enforce bounded resource allocation.

security 3-Layer Hallucination Firewall

Every inbound knowledge packet must pass through three strict cryptographic and semantic verification barriers:

  • Layer 1: Envelope & Gas Integrity
    Checks sender cryptographic signature, sequence monotonically decreasing gas limits, and schema structure.
  • Layer 2: Lexical Groundedness Entailment ($g \ge g_{\min}$)
    Computes semantic Jaccard and embedding bag overlap between claimed assertions and verified evidence chunks. Minimum threshold: 0.30.
  • Layer 3: Closed-Book Evidence Verification
    Zero ungrounded assertions allowed. Unbacked propositions trigger immediate packet rejection with convergence mode REJECTED.

alt_route Convergence & Deadlock Resolution

OSP negotiations transition across deterministic state machines:

  • RESOLVED: Consensus reached with groundedness verified by quorum $\ge \theta$.
  • REJECTED: Hallucination firewall triggered or signature verification failed.
  • MISMATCH: Conflicting evidence detected; initiates arbitration sub-swarm.
  • GAS_EXHAUSTED: Monotonic hop counter hit zero; prevents infinite query loops.
  • LOOP_DETECTED: Node visited previously in route trace path.

Guarantees $O(\text{gas})$ termination across arbitrarily complex decentralized network topologies.
