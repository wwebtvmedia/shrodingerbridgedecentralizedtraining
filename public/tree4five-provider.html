Tree4Five LLM Provider

A high-performance Android on-device LLM runtime built on java-llama.cpp. Exposes system-wide GGUF inference to autonomous agents via asynchronous AIDL IPC interfaces without battery-killing wakeups.

memory Native GGUF Execution Engine

Tree4Five provides native hardware acceleration across mobile chipsets:

  • Optimized JNI Bindings: Direct C++ JNI bridge into llama.cpp compiled with ARM NEON / FP16 extensions and Vulkan/OpenCL offloading.
  • Flexible GGUF Quantization: Runs Q4_K_M, Q5_K_M, Q8_0, and IQ4_XS quantized weights seamlessly with minimal RAM footprint.
  • Thermal & Battery Governor: Automatic CPU thread scaling and GPU offload regulation during sustained reasoning to prevent throttling.
  • Model Hub Downloader: Integrated HuggingFace GGUF direct streaming download with chunk resume and checksum verification.

cable AIDL IPC Architecture

Acts as an OS-level LLM daemon accessible by any authorized client app:

// ILLMService.aidl interface
package com.tree4five.gguf;

import com.tree4five.gguf.ILLMCallback;

interface ILLMService {
    boolean loadModel(String modelPath, int nGpuLayers, int contextLength);
    void generateStream(String prompt, float temperature, int maxTokens, ILLMCallback callback);
    void cancelGeneration();
    boolean isLoaded();
    String getActiveModelName();
}

Clients (such as HarnessDroid) bind to com.tree4five.gguf.LLMService via Intent and receive real-time streaming tokens through ILLMCallback.
